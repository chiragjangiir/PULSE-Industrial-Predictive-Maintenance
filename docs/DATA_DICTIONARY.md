# PULSE — DATA DICTIONARY

## 1. Dataset Overview

- **Dataset Name:** UCI AI4I 2020 Predictive Maintenance Dataset
- **Official UCI Source:** https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset
- **Authors:** Stephan Matzka, School of Engineering - Technology and Life, HTW Berlin, Germany
- **License:** Creative Commons Attribution 4.0 International (CC BY 4.0)
- **Total Records:** 10,000 instances

## 2. Raw Dataset Attributes & Semantic Roles

| Column Name | Data Type | Units / Range | Role in PULSE | Description & Leakage Policy |
|---|---|---|---|---|
| `UDI` | Integer | [1, 10000] | **EXCLUDED (Identifier)** | Unique Row Identifier. **Strictly excluded** from modeling to prevent trivial memorization leakage. |
| `Product ID` | String | e.g., 'L47181' | **EXCLUDED (Identifier)** | Product code prefix indicates Type (L/M/H) plus variant sequence number. **Excluded** from modeling. |
| `Type` | Categorical | {'L', 'M', 'H'} | **PREDICTOR (Categorical)** | Product quality variant: Low (50%), Medium (30%), High (20%). High variants are manufactured with tighter tolerances. One-hot encoded. |
| `Air temperature [K]` | Float | ~[295.3, 304.5] K | **PREDICTOR (Continuous)** | Ambient environmental air temperature measured in Kelvin. |
| `Process temperature [K]` | Float | ~[305.7, 313.8] K | **PREDICTOR (Continuous)** | Operating process temperature in Kelvin, generated by internal heat dissipation during manufacturing. |
| `Rotational speed [rpm]` | Integer / Float | ~[1168, 2886] rpm | **PREDICTOR (Continuous)** | Work spindle angular rotational velocity. High friction can drop rotational speed. |
| `Torque [Nm]` | Float | ~[3.8, 76.6] Nm | **PREDICTOR (Continuous)** | Torque applied by the tool spindle in Newton-meters. |
| `Tool wear [min]` | Integer / Float | ~[0, 253] min | **PREDICTOR (Continuous)** | Cumulative operational duration of the cutting tool bit since last replacement or sharpening. |
| `Machine failure` | Binary | {0, 1} | **PRIMARY TARGET** | Overall machine failure label (1 = failure occurred, 0 = normal operation). Benchmark imbalance: ~3.39% failure (339 cases). |
| `TWF` | Binary | {0, 1} | **EXCLUDED (Subtype Leakage)** | Tool Wear Failure indicator (tool replacement at 200-240 min). **Strictly excluded from predictors** to prevent circular ground-truth leakage. |
| `HDF` | Binary | {0, 1} | **EXCLUDED (Subtype Leakage)** | Heat Dissipation Failure indicator ($T_{proc} - T_{air} < 8.6\text{K}$ and speed $< 1380\text{rpm}$). **Strictly excluded from predictors**. |
| `PWF` | Binary | {0, 1} | **EXCLUDED (Subtype Leakage)** | Power Failure indicator ($P < 3500\text{W}$ or $P > 9000\text{W}$). **Strictly excluded from predictors**. |
| `OSF` | Binary | {0, 1} | **EXCLUDED (Subtype Leakage)** | Overstrain Failure indicator (torque $\times$ tool wear threshold). **Strictly excluded from predictors**. |
| `RNF` | Binary | {0, 1} | **EXCLUDED (Subtype Leakage)** | Random Failure indicator (uncorrelated 0.1% random failure chance). **Strictly excluded from predictors**. |

## 3. Engineered Features (Physics-Guided)

To enhance machine learning discrimination without ground-truth leakage, PULSE computes four physics-grounded interactions:

1. **`temp_diff`** ($K$):
   $$\text{temp\_diff} = \text{Process temperature [K]} - \text{Air temperature [K]}$$
   *Physics Meaning:* Measures thermal dissipation efficiency. A low delta under high load indicates heat trap or cooling system malfunction.

2. **`power_kW`** ($kW$):
   $$\text{power\_kW} = \frac{2\pi \cdot \text{Rotational speed [rpm]} \cdot \text{Torque [Nm]}}{60,000}$$
   *Physics Meaning:* Instantaneous mechanical power consumed by the spindle motor. Identifies abnormal electric motor draw or stall conditions.

3. **`torque_wear_interaction`** ($Nm \cdot min$):
   $$\text{torque\_wear\_interaction} = \text{Torque [Nm]} \times \text{Tool wear [min]}$$
   *Physics Meaning:* Cumulative mechanical fatigue and shear stress exerted on an aging cutting edge.

4. **`temp_ratio`**:
   $$\text{temp\_ratio} = \frac{\text{Process temperature [K]}}{\text{Air temperature [K]}}$$
   *Physics Meaning:* Relative temperature gradient tracking thermal expansion drift.
